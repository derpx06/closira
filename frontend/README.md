# Closira Frontend

Closira is an AI-powered customer communication platform for SMB teams.
This frontend provides:

- Public landing and product messaging
- Authentication (signup/login)
- Role-aware dashboards
- Conversation inbox and live chat views
- Team and knowledge hub management

## Tech Stack

- React + Vite
- Tailwind CSS
- React Router
- Axios + Socket.IO client

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- The app expects the backend API to be running and reachable via configured service endpoints.
- Branding and copy are aligned to Closira across landing, auth, dashboard, and admin sections.
